# 📊 Homicídios Globais (UNODC) - EDA e Regressão

Análise exploratória e predição das taxas de homicídios globais (2013-2022) utilizando a base de dados da UNODC. Entrega referente ao **Trabalho 01** da disciplina de Tópicos Especiais em Computação I.

### 💻 Tecnologias Utilizadas
Projeto inteiramente desenvolvido em **Python**, utilizando as seguintes ferramentas:
* **Pandas & Estatística Descritiva:** Limpeza e Análise Exploratória de Dados (EDA).
* **Scikit-Learn:** Criação do modelo de regressão para prever taxas de 2023 a 2026.
* **Streamlit:** Desenvolvimento da interface web interativa (Data App).
